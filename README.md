# Tanmay Mishra — Portfolio

> Backend-focused software developer building scalable APIs, microservices, and distributed systems.

### 🔗 Live site: **[tanmaymish.github.io/port](https://tanmaymish.github.io/port/)**

A personal portfolio showcasing my work in distributed systems, backend engineering, and
cybersecurity — including project deep-dives, an interactive skills breakdown, a live résumé,
and an animated security terminal.

## Highlights

- **Projects** — Doms Order Service (distributed order management), Event Stream Processing (Kafka, 1K+ events/sec), Oil Spill Detection (SIH 2024 Finalist)
- **HunterMind** — flagship AI-powered recon automation platform (in development)
- **Résumé** — embedded, viewable inline and downloadable as PDF
- **Security terminal** — animated `whoami` / recon / `nmap` session

## Tech Stack

- **Framework:** Next.js (App Router, static export)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **Deployment:** GitHub Pages

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000/port](http://localhost:3000/port) in your browser.

To build the static site:

```bash
npm run build
```

The exported site is generated in `out/`.
